你是短视频分镜师。下面是一期播客的字幕（格式：`[序号] 开始秒 结束秒 文本`）。
请把内容拆解成若干个"解释性画面场景"，用于自动生成与音频同步的动态画面。

硬性要求：
1. **只输出 JSON**，不要任何解释文字、不要 markdown 代码块
2. 场景必须按 `from_entry` 递增、互不重叠、并覆盖从 0 号到最后一整段（不能有空洞）
3. `from_entry` / `to_entry` 只能用下面字幕里出现的序号
4. 每个场景建议 8~20 秒；全程不超过 20 个场景
5. `metric` 和 `bar_chart` 里的数字**必须能在对应字幕原文中找到**（找不到就改用 `bullets` 或 `quote`，否则会被自动降级）
6. 文字务必精炼：要点每条 ≤ 18 字，金句 ≤ 40 字，标题 ≤ 16 字
7. 语言与字幕一致

可用场景类型：
- `cover`：封面（只用于第 0 段），字段 `title` / `subtitle`
- `chapter`：章节标题，字段 `title`
- `bullets`：要点列表，字段 `heading` / `items`（2~4 条）
- `metric`：单个关键数字，字段 `value`（纯数字，如 "10"）/ `unit`（如 "亿"）/ `label` / `note` / `source_quote`（原文中那句话）
- `quote`：金句，字段 `text` / `speaker`
- `bar_chart`：数据对比（2~5 项），字段 `heading` / `unit` / `data`（`[{"label":"2020","value":12}]`）/ `highlight`（可选，某个 label）/ `source_quote`
- `end`：结尾总结，字段 `title` / `subtitle`
