先问你一个问题👇

OpenAI 内部 99% 的 token，你知道都烧在哪个产品上吗？

不是 ChatGPT。
是 Codex——那个写代码的 Agent 🧐

ChatGPT 周活快 10 亿，Codex 才 2000 万左右，用户差了差不多 100 倍，token 消耗却完全反过来。
这说明什么？办公 Agent 才是真正的 token 大户、利润金矿。

而就在 8 月 25 日，字节憋的大招终于来了——
豆包工作，一个独立的办公 Agent 应用。
它不是原来的豆包 APP，而是有自己的客户端，你可以理解成 OpenAI 里 ChatGPT 和 Codex / ChatGPT Work 的区别：一个聊天，一个干活。

我为什么盯它盯了三个月？两个原因：
一是这产品一出来，大概率重新定义国内办公智能化；
二是我实在想知道，除了写文档、做 PPT 这些铺天盖地同质化的功能，它还能玩出什么新花样。

现在答案来了，三个点，最后一个最狠👇

🔥 一、它可能是中国最大的「token 黑洞」

豆包 APP 周活大概 2~3 亿（数量级推算），按 OpenAI 那个比例来算——
豆包工作周活冲到几百万、甚至千万级，不是梦。
到那个体量：国内最大办公智能体 ✅ 全球前三 ✅

但体量还不是最让我兴奋的。
真正狠的是：办公 Agent 烧 token 的速度，远超聊天机器人。
OpenAI 内部博客都说过，公司 99% 的 token 消耗来自 Codex。
沿用这套逻辑，豆包工作接下来可能吃掉全中国一半的 token 🤑
梁圣之前也公开讲过：正常卖 token、不做大补贴，利润高得吓人。

所以我的判断：半年内，它大概率成为中国最大的智能体——用户量、日均 token 消耗、营收规模，全维度碾压。
而且这影响会一路往上游传导：应用 → 模型研发 → 算力中心 → 国产芯片 → 能源。
这是中国 AI 产业链极其关键的一环，不是我夸张。

🔥 二、它一出生，就自带你的「工作记忆」

现在的 Agent 遍地都是，但历史几乎全是空白的——你得从零开始教它你的工作习惯。
豆包工作不一样。
它跟飞书是账号级打通的：你用飞书账号登录的第一秒，它就已经知道你过去两三年在飞书上的会议记录、文档、聊天记录，甚至组织架构、数据权限、功能权限，全部继承 😱

对企业来说这更炸裂。
老板最头疼的就是：员工用 Agent，数据权限怎么管？自己搭一套权限体系？又复杂又漫长。
豆包工作直接继承飞书现成的权限逻辑，这块成本直接省掉。
还记得飞书那场「小龙虾战役」吗？功能结构化梳理、CLI 开放，很多人早就拿 CLI 接自己的 Agent 了——但这次是账号级集成，权限范围内直接调用聊天记录、文档、会议纪要，更彻底。

前几周飞书和豆包合并成一个团队，当时好多人没看懂这步棋。
现在答案很清楚了：就是给豆包工作铺路。
我反复讲过，企业落地 AI 最重要的就是数据、就是企业上下文。
这层壁垒，豆包工作直接焊死了。

🔥 三、字节的看家本领，全给上 + 云端挂机

多模态：语音、图片、视频全部集成进豆包工作。
我自己一直用豆包输入法做语音输入，体验是真的顶。
视频更不用说——Seedance 2.0 / 2.5，公认断档领先的 SOTA 视频生成模型，直接放进办公场景，让 Agent 帮你高效调度管理。

还有一点很实用：
大部分 Agent 跑在你本地，电脑一合任务就断了。
豆包工作支持云端跑任务——电脑关了它还在干活 💻☁️
7×24 小时不停工的助手，批量处理、持续监控这些长任务，价值巨大。

最后总结一下我的看法：
豆包工作最核心的壁垒 = 飞书带来的企业上下文，其他 Agent 短期根本抄不走。
再加上字节的算力储备、模型积累、云端 Agent 架构、极强的企业产品运营能力——
接下来几个月，它大概率快速起量 🚀

已经在用飞书的团队和个人，迁移成本几乎为零：你的历史数据都在那。
官方还说了：激活就送 30 天会员权益，基本无缝接入。
