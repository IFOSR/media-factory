# Media Factory · 前端交互与视觉重构设计（Agent 思考链路版）

日期：2026-09-02
状态：已确认（brainstorming 三决策 + 步骤卡片三态机制）

## 背景与目标

现有 Web UI 功能齐全（改写/生图/播客/视频四步、附件、尺寸、免责声明、配置、任务档案），但交互与视觉停留在内部工具水平。本次重构目标：

1. **商用级视觉**：现代深色质感（Linear / Vercel / Raycast 风格）。
2. **Agent 思考链路**：像 Codex / Kimi Code 那样，流式展示后台每一步的处理逻辑（"正在做什么"），而非流式输出文案内容本身。
3. **产物内联交互**：中间产物紧跟其思考链路，可点击预览、可编辑更新。
4. **修复 bug**：改写文案目前渲染两次（打字机 + fetch 各一次）。

## 已确认的关键决策

- **决策 1（思考链路颗粒度）**：A 轻量级 —— 每步 2~4 条"动作日志"流式滚动，不接 LLM token 级真流式（后续增强）。
- **决策 2（产物交互区域）**：A 步骤内联 —— 产物紧跟其思考链路卡片，不做独立预览区。
- **决策 3（布局）**：左侧边栏（新建任务 + 历史列表）+ 主区思考时间线。
- **机制**：**步骤卡片三态合一** —— 同一张卡片随任务推进在 投料态 / 思考态 / 完成态 间切换。

## 整体布局

```
┌────────────┬──────────────────────────────────┐
│ 左侧边栏    │  主区（当前任务）                  │
│ ┌────────┐ │  ┌──────────────────────────────┐ │
│ │+ 新建任务│ │  │ 思考时间线（四张步骤卡片）      │ │
│ └────────┘ │  │  Step01 改写 · Step02 生图     │ │
│            │  │  Step03 播客 · Step04 视频     │ │
│ 历史任务    │  │  （纵向滚动 = 投料→产出叙事线） │ │
│ ────────  │  └──────────────────────────────┘ │
│ ● 任务-a   │  ┌──────────────────────────────┐ │
│ ○ 任务-b   │  │ 投料态时：四卡片为 input 表单   │ │
│   ...     │  │ + 底部 [一键全流程][仅从某步]   │ │
└────────────┴──────────────────────────────────┘
```

- **侧边栏**：顶部醒目「＋ 新建任务」；下方历史任务列表（状态圆点 + 任务 id + 当前步骤，点击即在主区回放该任务的完整时间线 + 产物）。
- **主区**：当前任务的思考时间线。新建任务时四卡片呈"投料态"；开始执行后逐卡切换"思考态 → 完成态"。

## 步骤卡片三态

每张步骤卡片（rewrite / image / podcast / video）是核心组件，三种状态：

| 状态 | 触发 | 卡片内容 |
|------|------|---------|
| **投料态** | 新建任务 / 步骤未运行 | 该步骤可选 input 表单（见下） |
| **思考态** | 步骤 running | 思考日志区，日志行流式滚动，左侧时间线圆点呼吸 |
| **完成态** | 步骤 done | 产物卡片（可预览 / 可编辑 / 可更新） |

步骤 input 表单（投料态）：

- **Step 01 改写**：参考文案（必填 textarea + 📎上传文档）、改写要求（可选 textarea）
- **Step 02 生图**：生图要求（可选 textarea + 📎参考图多附件）、尺寸下拉（方形/竖屏/横屏）、免责声明勾选
- **Step 03 播客**：播客风格（可选 textarea）、人数下拉（1/2）、主持人/嘉宾音色下拉
- **Step 04 视频**：字幕样式（可选，后续扩展）

卡片折叠态：非活动步骤折叠为一行（步骤名 + 状态图标 + 产物缩略 chip）。

## 思考链路事件协议（后端新增）

当前 `Event` 枚举只有粗粒度 step 状态。新增动作日志事件：

```rust
pub enum Event {
    Step { step, status },          // 已有
    Log { step, text },             // 新增：思考链路动作日志
    Chunk { step, delta },          // 保留但前端不再用于改写文案打字机
    Artifact { step, name, url },   // 已有
    Progress { step, percent },     // 已有（预留）
    Task { status, error },         // 已有
}
```

`TaskEvents` 新增方法：

```rust
pub fn log(&self, step: Step, text: &str);  // 发 Event::Log
```

各步骤埋点（在 `src/cmd/*.rs` 关键节点调用 `events.log(...)`）：

- **rewrite**：`读取参考文案与改写要求` → `调用语言模型（{provider}）` → `已生成改写稿（N 字）`
- **image**：`提炼图像 prompt` → `调用生图服务（{model}，{size}）` →（可选）`叠加免责声明` → `已保存配图`
- **podcast**：`整理播客输入（N 人）` →（模式B）`生成对话脚本` → `调用火山播客服务` → `捕获字幕时间轴` → `已合成音频`
- **video**：`校验图片与音频` → `渲染字幕` → `ffmpeg 合成视频` → `已生成成品`

CLI 模式 `TaskEvents::local` 下 `log` 退化为 `println!`（终端同样可见思考链路）。

## 产物卡片交互

完成态产物按类型渲染：

- **文案（rewritten.md / script.md）**：可编辑 textarea + 保存按钮（复用现有 `PUT /api/files/:id/:name`），保存后提示"后续步骤将基于修改后的内容"。
- **配图（image.png）**：缩略图，点击放大到灯箱（lightbox 弹层）；保留免责声明叠加结果。
- **音频（podcast.mp3）**：内联 `<audio>` 播放器。
- **字幕（subtitle.srt）**：只读文本预览。
- **视频（video.mp4）**：内联 `<video>` 播放器。

**移除**改写文案的 `typewriter` 假打字机（修复重复渲染 bug）：改写文案只在 `artifact` 事件到达后渲染一次（完成态卡片）。

## 视觉系统（设计 token）

深色为主，浅色跟随系统/可切换（保留现有 localStorage 记忆）：

```
--bg        #0c0d11   （页面底）
--panel     #14161c   （卡片底）
--panel-2   #1a1d25   （嵌套/输入底）
--line      rgba(255,255,255,.07)  （微光边框）
--line-strong rgba(255,255,255,.14)
--text      #e8eaee
--muted     #8b90a0
--accent    #6e7bff   （主强调，克制 indigo）
--accent-soft rgba(110,123,255,.12)
--ok        #4ade80  --warn #fbbf24  --err #f87171
--mono      "SF Mono","JetBrains Mono",monospace
```

- 卡片：圆角 12px + 1px 微光边框 + 轻微内阴影；hover 边框提亮 + 2px 上浮。
- 思考日志：等宽字体、小号、muted 色、逐行淡入；当前行动态高亮（左侧竖条 accent）。
- 时间线：步骤卡片左侧一条竖线串联，圆点状态（pending 灰 / running accent 呼吸 / done 绿 / failed 红）。
- 玻璃拟态：弹层 `backdrop-filter: blur(12px)`。
- 不再使用 `//` 前缀标题与大面积琥珀色，改用克制的 indigo 强调。

## 数据流

1. 侧边栏点「＋ 新建任务」→ 主区渲染四张投料态卡片。
2. 填写 → 点「一键全流程」/「仅从某步」→ `POST /api/<step>`，返回 `task_id`。
3. 前端 `subscribe(task_id)`：先 `GET /api/tasks/:id` 回放（补建立 SSE 前的事件），再 `EventSource` 订阅 SSE。
4. SSE 事件驱动：`log` → 追加思考日志；`step` → 切换卡片状态；`artifact` → 渲染产物卡片；`task` → 收尾 + 刷新侧边栏列表。
5. 产物编辑 → `PUT /api/files/:id/:name` → 后端写文件，后续步骤读取新内容。

## Bug 修复清单

1. **改写文案渲染两次**：删除 typewriter，artifact 事件统一渲染一次。
2. 历史任务展开时产物重复 fetch（防御性去重）。
3. SSE 断线后状态残留（`es.onerror` 兜底 + 任务终态轮询）。

## 不做的事（YAGNI）

- 不接 LLM token 级真流式（后续增强）。
- 不做独立预览面板 / 三栏工作台。
- 视频步骤的字幕样式自定义 input 仅占位，不实现复杂字幕编辑。
- PDF/Word 参考文档解析（当前仅 md/txt）。
